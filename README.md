# HELIOS 2.0 — هيليوس
## Orbital Engineering Lab 02 | مختبر الهندسة المدارية

محاكاة فضائية تفاعلية ثلاثية الأبعاد في نسختين مستقلتين في دورة الإصدار. نسخة Android 2.0 مجمدة على نسخة الويب المثبتة، ويستمر تطوير الويب دون إعادة بناء Android تلقائيًا.

## النسخة الثانية

- 4200 نجمة، كوكب إجرائي، بنية مدارية مفصلة، ست وحدات ومحاكاة الطاقة.
- معالجة رسومية بعدية تشمل تأثير توهج الشاشة (Bloom) وتظليل الحواف، وتحسين المواد والإضاءة الاتجاهية. لا تُحاكى ظلال الأجسام على بعضها أو انعكاسات الأشعة.
- أربع درجات للجودة: تلقائية متكيفة مع الأداء، اقتصادية، عالية، سينمائية (Ultra حتى 8.3 مليون بكسل إذا سمحت الشاشة والجهاز). لا توجد حدود مفروضة بناء على حاسوب المالك.
- كاميرات مدارية وعلوية وجانبية ومنظور الكوكب، جولة آلية، تفكيك الوحدات وإعادة تركيبها.
- قيادة مركبة صيانة في ثلاثة محاور، قصور حركي وتثبيت السرعة، مسافة وسرعة حية، التحام يدوي أو مساعد. نموذج حركي مبسط وليس محاكاة ميكانيكا مدارية حقيقية.
- واجهة عربية، لمس متعدد، لوحة مفاتيح، وتجربة ملء الشاشة.

## التشغيل والنشر

### الويب
يمكن فتح index.html محليًا بلا خادم ولا شبكة. يتضمن المستودع .nojekyll للنشر المباشر من الفرع main/root. إذا استمر فشل Pages، غيّر Settings → Pages → Source إلى **GitHub Actions** ثم شغّل **Deploy HELIOS website** من Actions. لا تستخدم مصدرين متزامنين. نشر الموقع غير مشروط بنتيجة اختبار المتصفح.

### Android
نسخة HTML المضمّنة في Android محفوظة مستقلّة في android/app/src/main/assets/index.html. تعديل index.html الرئيسي لا يطلق بناء APK ولا يغير محتوى نسخة Android. مشروع Gradle داخل android/، تطبيق Android مستقل بحزمة io.github.scientifica007.helios، API 23+، WebView مسرّع عتاديًا، ومحتوى المحاكاة مضمّن في APK. لا يحتاج إذن الإنترنت ولا يعتمد على رابط الموقع. يتطلب دعم WebGL وتحديث Android System WebView بما يتوافق مع الجهاز.

بناء محلي عند توفر JDK 17 وGradle 8.9 وAndroid SDK 35:

```bash
gradle -p android :app:assembleDebug
```

يقوم workflow **Build Android APK** بالبناء، والتحقق من التوقيع ومطابقة صفحة HTML المضمّنة، ونشر ملف HELIOS-android.apk وSHA-256 في Releases. البناء تجريبي موقّع بمفتاح debug الخاص ببيئة البناء؛ ليس إصدار متجر رسميًا. قد تتطلب النسخ اللاحقة إزالة الإصدار السابق إذا اختلف مفتاح التوقيع.

## التحكم

اسحب المشهد للدوران، استخدم إصبعين أو عجلة الفأرة أو +/− للتقريب، اختر وحدة للفحص، وR للعودة. في وضع القيادة اضغط باستمرار على أزرار المحاور لتحريك المركبة؛ زر تثبيت يوقف سرعتها، ومساعدة الالتحام تقودها نحو الهدف تلقائيًا. الالتحام يتطلب مسافة أقل من 0.30 وسرعة أقل من 0.55 بوحدات النموذج.

## النموذج الرياضي

```
generation = 36 + 124 × max(0, cos((solarAngle − 18)°)) × illumination / 100
load = 30 + 0.95 × demand
net = generation − load
battery change = net × elapsed simulation seconds / 120
```

## حالة التحقق

- نجح اختبار منطقي للنسخة الثانية باستخدام واجهة WebGL محاكية: تشغيل المشهد، فحص الوحدات، العجز والفائض، التفكيك، الدفع اليدوي، التثبيت، الالتحام المساعد، تبديل الجودة والكاميرا، وإعادة التهيئة. لا يثبت هذا الاختبار جودة الرسم الفعلي.
- اختبار Chromium الفعلي: تابع Actions. ثُبت Ubuntu 24.04 لتوافق Playwright 1.51.1.
- بناء APK وتفعيل الموقع واختبارهما فعليًا: لا يعدّان مؤكدين إلا بعد نجاح خطوط البناء والنشر والتحقق من الروابط.
- محاكاة تعليمية خيالية، ليست أداة هندسة فضائية معتمدة.

## HELIOS Web 3.0 — Interior exploration

الدخول من قائمة المشهد ← دخول المحطة، أو الاقتراب من المنفذ الجديد عند الطرف +Z في التحليق الحر. غرفة العزل، الحلقة السكنية والمختبر تشترك في الإحداثيات والهندسة مع الغلاف الخارجي، وليست مشهدًا منفصلًا. استخدم أزرار الحركة أو WASD والسحب للنظر، وF أو زر تفاعل عند الاقتراب من باب أو جهاز. لإخلاء غرفة العزل أغلق الباب الداخلي أولًا؛ يفتح المنفذ الخارجي ثم تنتقل الكاميرا إلى الخارج. يمكن العودة سريعًا إلى غرفة العزل من قائمة المشهد، أو العودة إلى المدار. ثلاث معاينات داخلية مستقلة: الطاقة (قراءة النموذج)، دعم الحياة (تبديل حالة افتراضية)، المختبر (تشغيل جهاز فحص افتراضي). لا تشمل هذه النسخة التجول داخل المفاعل أو ميناء الالتحام العمودي أو محاكاة الضغط أو انعدام الجاذبية أو الظلال الفيزيائية. المشي الداخلي مقيد بالأرضية وتمنعه الجدران والأبواب المغلقة والتجهيزات المحددة. التحليق الخارجي لا يزال بلا تصادم شامل. نسخة Android 2.0 لم تتغير.

## HELIOS Web 3.1 — Session log

القائمة ← سجل التجربة ← تصدير JSON. التسجيل المحلي نشط افتراضيًا منذ فتح الصفحة، ويمكن إيقافه واستئنافه أو بدء سجل جديد بعد التأكيد. لا تخزين دائم ولا إرسال تلقائي. يتضمن المخطط `helios.session.v1` إصدار التطبيق، الأحداث، عينات الكاميرا والمحاكاة (تقريبًا كل ثانية)، الغرف، التفاعلات، محاولات الحركة الممنوعة، مؤشرات FPS والملاحظات الاختيارية. يحتفظ السجل بحد أقصى 4000 حدث و7200 عينة ويحصي العناصر المستبعدة. القياسات تقريبية ولا تسمح بإعادة تشغيل التجربة حرفيًا. لا يتضمن السجل الموقع الجغرافي أو معرّف الجهاز أو عناوين IP. يُفقد السجل عند إعادة تحميل الصفحة ما لم يُصدّر. يمكن إرسال JSON يدويًا للمطور لتحليل تجربة المستخدم. Android 2.0 ثابت.
