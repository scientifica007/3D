# HELIOS — هيليوس
### Orbital Engineering Lab 01 | مختبر الهندسة المدارية

تجربة فضائية تفاعلية ثلاثية الأبعاد، مبنية بمحرك WebGL 1 مستقل، دون مكتبات خارجية أو أصول رسومية جاهزة. جميع المجسمات تولد برمجيًا.

**[رابط الموقع بعد تفعيل GitHub Pages](https://scientifica007.github.io/3D/)** · **[ملف التطبيق](index.html)** · **[نتائج الاختبارات الآلية](https://github.com/scientifica007/3D/actions)**

## ماذا يمكنك أن تفعل؟

- استكشاف ست وحدات: المفاعل، الألواح الشمسية، حلقة الإقامة، ميناء الالتحام، المختبر ومنظومة الدفع.
- تدوير المشهد، التكبير، اختيار الوحدات، جولة كاميرا آلية.
- تفكيك الوحدات وإعادة تجميعها بحركة انتقالية، وعرض مسارات الطاقة.
- مراقبة مركبة الصيانة المدارية والكوكب والنجوم.
- تغيير زاوية الألواح هندسيًا، والطلب والإضاءة وسرعة الزمن، ومراقبة البطارية والحرارة.
- إتمام بروتوكول فحص من أربع مهام؛ يبدأ بعجز طاقي يتطلب تدخل المستخدم.

## التشغيل

حمّل `index.html` من GitHub وافتحه في متصفح يدعم WebGL. لا حاجة إلى خادم أو تثبيت أو اتصال بالإنترنت.

للنشر: **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**. بعد اكتمال النشر يكون الموقع على الرابط أعلاه.

## نموذج المحاكاة

```
generation = 36 + 124 × max(0, cos((solarAngle − 18)°)) × illumination / 100
load = 30 + 0.95 × demand
net = generation − load
battery change = net × elapsed simulation seconds / 120
```

الفيزياء مبسطة والقيم افتراضية للتعليم والعرض. الإضاءة اتجاهية سطحية وليست ظلالًا ساقطة بين الأجسام. مسارات الطاقة مخطط بصري وليس شبكة كهربائية معتمدة.

## التحقق

- نجح اختبار منطقي أولي بواجهة WebGL محاكية: التهيئة، التفاعل، الحالات المتغيرة، إتمام المهام، إعادة التهيئة، وسلامة القيم العددية.
- أضيف اختبار Chromium فعلي عبر Playwright في `tests/browser.mjs` وGitHub Actions. لا تعد نتيجته مؤكدة قبل اكتمال التشغيل.
- بيئة التطوير المحلية لم توفر سياق WebGL عند محاولة الاختبار المباشر؛ لم تجر معاينة بصرية نهائية فيها.

لإجراء اختبار المتصفح محليًا:

```bash
npm install --no-save playwright
npx playwright install chromium
node tests/browser.mjs
```

يحفظ الاختبار ثلاث لقطات (سطح المكتب، التفكيك، الهاتف) في `artifacts/`.
