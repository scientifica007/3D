# FT-002 — بروتوكول مقترح لتقييم HELIOS Web 3.2.0 (build 11)

الحالة: بروتوكول جاهز، لم تُنفّذ التجربة بعد. المرجع الميداني: [FT-001](2026-11-27-session-001/report.md). لا تعديل لسجل FT-001.

## التغييرات المنفذة

- القياس: مخطط JSON القديم helios.session.v1 محفوظ، مع حقول إضافية اختيارية: performance_samples، retained_performance_samples، dropped.performance_samples. كل نافذة أداء foreground تقارب ثانية، تسجل t_ms وduration_ms وframes وfps وسياق البداية والنهاية (الوضع، المنطقة، الجودة، أبعاد الرسم والنافذة، فتح القائمة). mixed_context يعني أن السياق تبدل داخل النافذة؛ لا ينسب انخفاض الأداء إلى مكان بعينه في هذه الحالة. تُصفّر النافذة الجزئية عند إيقاف التسجيل أو إخفاء الصفحة. حد الاحتفاظ 7200 عينة أداء، مستقل عن 7200 عينة محاكاة و4000 حدث. القياس ليس اختبار GPU مستقلًا.
- التفاعل: door_interaction وequipment_interaction يميزان accepted/rejected مع reason، وdoor_state يسجل completed عند انتهاء حركة الباب. door_safety_reopen يوثق إعادة الفتح الوقائي. الانتقالات المباشرة وإعادة ضبط غرفة العزل ليست حركة باب عادية ولا يصح اعتبار كل طلب مقابل اكتمال واحد.
- القيادة: مؤشر الهدف المرئي عند وجوده داخل الشاشة، فرق X/Y/Z، سرعة الاقتراب C (موجبة نحو الهدف)، تمييز محور تصحيح مقترح، وتحذير تثبيت عند الحركة غير الملائمة. الدفع الدقيق يخفض التسارع اليدوي من 2.4 إلى 0.6 U/s²؛ لا يغير قانون الالتحام المساعد أو شروطه (المسافة <0.30 U والسرعة <0.55 U/s).
- الطاقة: سياسة تعليمية، عند عجز التوليد مع بطارية فارغة تُخفض الإضاءة الداخلية ويتوقف فحص المختبر، دون تعطيل فتح أبواب العزل أو فحص الطاقة أو التحكم الافتراضي بدعم الحياة. العودة إلى الوضع العادي عند كفاية التوليد (صافي الطاقة >=0)، أو بلوغ 5% بطارية في حالة الطوارئ مع عجز قائم. القدرة والحمل المطلوبان ومعادلة البطارية السابقة لم تتغير؛ لا توجد ميزانية أحمال منفصلة أو محاكاة ضغط/دعم حياة فيزيائية. تُسجل power_mode والرفض insufficient_power. 
- لا تغيير لنسخة Android 2.0. لا إرسال تلقائي لسجلات التجربة. 

## خطة التحقق الميداني

1. قبل البدء: حدّث الموقع وتحقق من COMMAND · 11، واستعمل الهاتف والجودة auto كما في FT-001 قدر الإمكان. دوّن أي اختلاف في المتصفح أو اتجاه العرض أو الجودة. ابدأ تسجيلًا جديدًا.
2. استكشف بحرية أولًا: ادخل المحطة وزر المناطق الداخلية الأربع وتفاعل مع التجهيزات. جرّب فتح المنفذ مع الباب الداخلي مفتوحًا ثم نفّذ الخروج الصحيح.
3. جرّب الالتحام اليدوي: استخدم مؤشرات X/Y/Z وC، وقارن نمط الدفع المعتاد بالدقيق. لا تستخدم الالتحام المساعد إذا كان الهدف مقارنة القيادة اليدوية في FT-001. سجّل إن استخدمته.
4. تجربة الطاقة الموجهة في آخر الجلسة: في الأنظمة اضبط الإضاءة المدارية 0% والطلب 100% وسرعة الزمن 4×؛ اترك المحاكاة نشطة إلى ظهور الطوارئ. جرّب فحص المختبر في وضع الطوارئ، ثم ارفع الإضاءة إلى 100% (زاوية الألواح الافتراضية 35°) وتحقق من العودة إلى الوضع العادي وإمكانية الفحص. لا تُفسر التغييرات على أنها قياسات فيزيائية.
5. أضف ملاحظاتك، أوقف التسجيل، ثم صدّر JSON. لا تنشره تلقائيًا.
